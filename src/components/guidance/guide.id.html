Aplikasi ini mensimulasikan beban kerja operator di lantai produksi: berapa mesin yang sanggup ditangani satu operator, berapa man occupation-nya, dan berapa output yang dihasilkan dalam satu shift.

Ringkasan & peran

Ada dua simulator. Work Load Simulator mensimulasikan satu operator yang menangani sekumpulan mesin dengan satu Construction Detail. Production Simulation mensimulasikan banyak operator dan banyak Construction sekaligus pada satu layout pabrik.

Work Load Simulator

Alurnya dua tahap: 1. Setup lalu 2. Simulation. Setup sendiri terdiri dari dua langkah: Setup dan Machine Layout.

Langkah 1 — Setup

  1. Pilih Construction Detail di bagian atas (bisa difilter per Area, Mach, Product). Aplikasi mengisi Machine Specification dari WL_Products dan Activity Table dari WL_Activities. Setting operator (Task Priority, shift, lunch, meeting, RPC, Walking Speed, Doff Priority) diisi dari Setting → Default Values.
  2. Machine Specification: LayLength, NoOfWires, Speed, SpoolLength, LinearDensity, Fracture/Dies/Defect per ton, POlength. Dari sini dihitung Spool Weight dan Runtime/spool.
  3. Operator Activities: Task Priority, Shift Time, Lunch/Meeting (durasi dan menit mulainya), break tambahan (+ Add activity), Available Time beserta Walking Speed (m/menit) di sampingnya, serta Doff Priority dan Min Remain Task for Doff Priority di bagian paling bawah.
  4. Output Estimate: perkiraan output dan man occupation sebelum simulasi dijalankan. Atur # Assigned Machines, atau klik Optimize Man Occupation agar aplikasi mencari jumlah mesin terbanyak tanpa backlog.
  5. Activity Table: Time, Frequency Type, Numerator, Denominator, dan Mach Condition per aktivitas. RPC % ada di kanan judul tabel. Tambah sub-aktivitas dengan + Sub Doffing atau + Sub Loading.

Tombol ikon panah melingkar mengembalikan semua isian ke kondisi saat Construction Detail dipilih.

Langkah 2 — Machine Layout

  1. Pilih layout tersimpan dari Layout Builder, atau susun langsung di kanvas.
  2. Pilih mesin lalu Assign. Jumlah mesin yang di-assign harus sama dengan # Assigned Machines.
  3. Opsional: tentukan titik awal operator (operator start point). Kalau tidak ada, operator mulai dari mesin pertama.
  4. Klik Validate & Start Simulation.

Tahap Simulation

  • ▶ Play, ⏸ Pause, pilihan kecepatan, dan Reset. # Mach Assigned dan Fracture per Ton hanya bisa diubah setelah Reset.
  • Operator Timeline dan Machine Timeline menampilkan apa yang terjadi tiap menit. Klik segmen operator untuk menandai mesin terkait, klik baris mesin untuk ringkasan mesin itu.
  • Dashboard: Output (Running Time), Output, Man Occupation, OEE & Downtime, Completed Activities, Activity Log.
  • Save WLM menyimpan hasil ke WL_Outputmodels. Kalau Construction Detail itu sudah punya hasil tersimpan, muncul perbandingan dengan versi lama; Anda bisa mengganti versi lama atau menyimpan versi baru (Version remark wajib diisi untuk versi baru).
  • Setelah shift selesai: lihat detail output, atau Copy output (format tab, bisa ditempel ke Excel).

Layout Builder

Tempat membuat layout mesin yang bisa dipakai ulang di kedua simulator.

  • Add Group Machine: buat sekelompok mesin dengan jumlah baris, kolom, orientasi (Vertikal: PO atas, TU bawah; Horizontal: PO kiri, TU kanan), Pair/Single, dan ukuran mesin (meter).
  • Pilih mesin untuk menyalin/menempel (Ctrl+C / Ctrl+V, termasuk tempel berulang ke kiri/kanan), membalik orientasi, mengubah tipe BF/X, mengubah ukuran, atau menomori ulang.
  • Wall (dinding): operator harus berjalan memutarinya. Remark: catatan teks, tidak menghalangi jalan.
  • Measure distance untuk mengukur jarak, dan operator start point untuk titik awal operator.

Production Simulation

Membuat Production Setup

  1. Pilih Layout, isi nama setup, klik + New Setup. Layout disalin ke setup (perubahan layout sesudahnya tidak ikut). Nilai awal shift dan movement diambil dari Setting → Default Values.
  2. Isi Shift & Movement Settings: Task Priority, Shift/Lunch/Meeting, RPC %, Doff Priority, Min Remain Task, Walking Speed.
  3. Tambah operator di card Operators: satu per satu, atau sekaligus dengan prefix dan jumlah (contoh Opr_0001). Angka di samping nama operator adalah forecast man occupation-nya.

Assign Selection

Pilih mesin di kanvas (klik atau drag), lalu isi dari atas ke bawah. Setiap field punya tombol Apply dan tombol hapus. Tombol Apply berwarna kuning kalau isiannya belum di-apply.

  1. Construction Detail mesin.
  2. Group Name: label bebas untuk pelaporan mesin yang dikelompokkan.
  3. Tab Assign Type: hanya menentukan field operator yang tampil; tidak disimpan.
    • Multi Task → tambahkan satu atau beberapa operator. Siapa pun di antara mereka bisa mengerjakan tugas apa pun di mesin itu.
    • Split Task → tambahkan satu atau beberapa operator per aktivitas: Doff, Load, Fract, Dies, Defect. Mereka hanya mengerjakan aktivitas itu.
  4. Doff Priority (opsional): toggle dan Min Remain Task khusus mesin terpilih. Tombol hapus mengembalikannya agar ikut setting setup.

Satu mesin bisa punya operator Multi Task dan Split Task sekaligus. Mengganti Assign Type tidak menghapus operator tipe lainnya; keterangan di bawahnya menampilkan siapa saja. Satu operator hanya masuk salah satu di sebuah mesin: operator yang sudah Multi Task di mesin terpilih tidak muncul di Split Task, begitu juga sebaliknya. Mesin yang belum punya operator terbuka sebagai Multi Task.

Setiap kotak operator menampilkan man occupation mesin terpilih bila pekerjaan itu dikerjakan satu operator: kotak Multi Task untuk semua task, setiap kotak Split Task untuk aktivitasnya, beserta ideal demand di sampingnya. Kotak seleksi di kanvas menampilkan All Task dan semua aktivitas.

Card Operators

  • ⚙️: jam mulai Lunch/Meeting khusus per operator. Kosong = mengikuti setup. Durasi tetap dari setup.
  • 📊: Planned Man Occupation layar penuh, termasuk beban yang belum ada operatornya.

Kanvas & Machine Assignments

  • Construction Detail View mewarnai mesin per Construction. Operator View membagi badan mesin per operator. Arahkan kursor ke legend untuk menyorot mesinnya; legend punya tab Construction, Operator, dan Machine Group.
  • Tabel Machine Assignments menampilkan semua kolom per mesin: Construction, Group Name, Multi Task, operator per aktivitas (arahkan kursor ke jumlahnya untuk melihat nama-namanya), dan Doff Priority mesin ("—" = ikut setup). Baris di atas header berisi total tiap kolom (jumlah mesin, Construction, group, dan operator yang berbeda). Group by Construction, Group Name, atau Operator merangkum tabel per grup: berapa mesin, Construction, group, dan operator (total, Multi Task, dan per aktivitas). Untuk Operator, satu mesin dihitung di setiap operator yang mengerjakannya. Klik header kolom mana pun untuk mengurutkan; klik lagi untuk membalik urutan. Search hanya menampilkan mesin yang mengandung teks itu di kolom mana pun (mesin, Construction, Group Name, operator mana pun, Doff Priority); total dan Group by lalu hanya menghitung mesin tersebut.
  • Gunakan Export CSV, edit di Excel, lalu Import CSV. Kolom Multi Task dan kolom aktivitas diisi nama operator dipisah ;. Kolom Doff Priority diisi Yes, No, atau kosong; Min Remain Task diisi angka menit atau kosong (kosong = ikut setup).

Menjalankan simulasi

Klik ▶ Run Simulation. Di halaman hasil: timeline operator dan mesin (klik nama operator untuk memfilter card Man Occupation), Operator List, Output (dipisah Finish Product dan Semi Finish Product berdasarkan SpoolType BS…), Reject % untuk OEE Quality, Downtime Pareto, dan tombol Production Report. Production Report bisa mengelompokkan hasil per kolom WL_Products atau per Machine Group (Group Name mesin).

Setting → Default Values

Nilai awal untuk Production Setup baru dan untuk Work Load Simulator setiap kali Construction Detail dipilih: Task Priority, Shift Time, Lunch Time, Lunch starts at, Meeting Time, Meeting starts at, RPC %, Walking Speed, Doff Priority, Min Remain Task for Doff Priority. Klik Save untuk menyimpan.

Aturan simulasi

Task Priority

Nearest Task: operator mendatangi mesin antrean yang jarak jalannya terdekat. Quickest Task: operator memilih mesin yang pekerjaannya selesai paling cepat (jalan + seluruh waktu kerja).

Mach Condition: Run dan Stop

  • Aktivitas Stop menghentikan mesin selama dikerjakan; mesin juga berhenti selama menunggu operator.
  • Aktivitas Run dikerjakan sambil mesin tetap jalan.
  • Aktivitas Run yang langsung diikuti aktivitas Stop ikut menghentikan mesin. Ini juga berlaku kalau aktivitas Stop berikutnya milik operator lain dan masih menunggu di mesin itu.

RPC (Rest & Personal Care)

Setiap aktivitas mendapat tambahan waktu sebesar RPC % dari waktunya. Contoh: RPC 12% membuat aktivitas 10 menit menjadi 10 + 1,2 menit. Waktu RPC tampil sebagai segmen sendiri di timeline (legend "RPC") dan sebagai Others (RPC) di Man Occupation. RPC berperilaku seperti aktivitas Run: mesin hanya ikut berhenti kalau aktivitas setelahnya Stop, dan waktunya lalu dicatat sebagai downtime aktivitas induknya.

Doffing, Loading, dan sub-aktivitas

  • Loading mengikuti POlength di WL_Products bila diisi. Area WW, BA, CA, IS, IP memakai Loading berbasis berat yang dikerjakan di Pay Off.
  • Kalau Loading Partial1 dan Partial2 jatuh tempo bersamaan, keduanya diganti satu Loading Partial3.
  • Kalau Doffing dan Loading satu mesin dipegang operator berbeda, Loading menunggu sampai Doffing selesai; jeda itu tercatat sebagai waiting.

Fracture Repairing, Dies Change, Defect Repairing

Ketiganya dihitung per Construction, bukan per mesin: begitu jumlah spool gabungan mesin ber-Construction sama mencapai siklusnya, kejadian jatuh ke salah satu mesin yang sedang jalan secara acak. Dies Change berlaku untuk Area WW, BA, CA, dengan 7 atau 26 dies per kejadian. Defect Repairing berlaku untuk Area CB, BU, SP, CH, CR dan dikerjakan di Take Up.

Multi Task vs Split Task

Satu task di mesin bisa dikerjakan operator Multi Task mesin itu dan operator Split Task aktivitas tersebut, siapa yang lebih dulu kosong (sesuai Task Priority). Satu mesin hanya dikerjakan satu operator pada satu waktu. Subtask (misalnya ScanMES, Loading Partial) ikut aktivitas induknya. Loading menunggu Doffing selesai kalau operatornya tidak bisa mengerjakan Doffing juga. Dies Change dan Defect Repairing memakai operatornya sendiri; kalau kosong, ikut operator Fracture Repairing. Di forecast, beban satu aktivitas dibagi rata ke semua operator yang bisa mengerjakannya.

Break (Lunch, Meeting, Other)

Saat jam break tiba, operator menyelesaikan kunjungan yang sedang dikerjakan dulu, lalu break dengan durasi penuh. Selama break, mesin yang butuh dikerjakan menunggu. Di Production Simulation, jam mulai bisa berbeda per operator (tombol ⚙️).

Doff Priority

Kalau Yes: saat operator sedang mengerjakan mesin dan mesin lain butuh Doffing, sementara sisa kunjungannya masih ≥ Min Remain Task menit, pekerjaan itu ditunda. Operator mengerjakan semua Doffing yang menunggu (sesuai Task Priority), lalu memilih lagi sesuai Task Priority. Pekerjaan yang ditunda dinilai dari sisa waktunya dan dilanjutkan dari titik terakhir. Pekerjaan Doffing sendiri tidak pernah ditunda.

Di Production Simulation, setiap mesin bisa punya Doff Priority dan Min Remain Task sendiri (di Assign Selection). Yang dipakai adalah setting mesin yang butuh Doffing; kalau kosong, mengikuti setting setup. Mesin dengan Doff Priority No tidak menyela pekerjaan lain dan tidak didahulukan.

Doff Priority mengurangi waktu tunggu Doffing, tapi menambah waktu jalan operator. Naikkan Min Remain Task bila penundaan terlalu sering.

Glosarium

Construction
Kode konstruksi produk; teksnya memuat Mach-Product-LayLength-TG-SpoolType.
Construction Detail
Satu baris WL_Products; dasar spesifikasi mesin dan Activity Table.
Area
Area produksi (BU, CB, SP, CH, CR, WW, IS, IP, CA, BA); menentukan aturan Loading, Dies Change, dan Defect Repairing.
Spool
Satu gulungan hasil mesin. Spool Weight = SpoolLength × LinearDensity × NoOfWires ÷ 1000 (kg).
Runtime/spool
Waktu mesin memproduksi satu spool.
Doffing
Mengambil spool jadi dari mesin, di Take Up.
Loading
Mengganti/mengisi bahan baku; Loading Partial adalah loading sebagian.
Fracture Repairing
Memperbaiki kawat putus.
Dies Change
Mengganti dies.
Defect Repairing
Memperbaiki cacat produk.
Pay Off / Cradle / Take Up
Zona kerja di mesin tempat operator berdiri (PO, cradle, TU).
Mach Condition
Stop (mesin berhenti) atau Run (mesin tetap jalan) saat aktivitas dikerjakan.
Num / Dem
Numerator / Denominator: aktivitas terjadi Num kali setiap Dem spool.
Frequency Type
Aturan frekuensi berbasis event untuk subtask Doffing.
RPC
Rest & Personal Care: tambahan waktu % untuk istirahat dan keperluan pribadi.
Task Priority
Cara operator memilih mesin berikutnya: Nearest atau Quickest.
Available Time
Shift Time dikurangi Lunch, Meeting, dan break lain.
Man Occupation
(Walking + Handling) ÷ waktu kerja bersih, dalam %.
Ideal demand / Forecast
Beban kerja teoretis vs perkiraan setelah memperhitungkan mesin berhenti dan jalan kaki.
Others (RPC)
Porsi waktu RPC di Man Occupation.
Idle
Operator tidak ada pekerjaan.
Downtime / Waiting
Mesin berhenti: karena aktivitas Stop, atau menunggu operator.
OEE Availability
(Waktu produksi terencana − downtime) ÷ waktu produksi terencana.
Reject % / Quality
Persentase tonase reject; mengurangi tonase baik dan OEE (Production Simulation).
Manhour/ton, Machhours/ton
Jam operator atau jam mesin per ton output.
Multi Task / Split Task
Operator yang bisa mengerjakan semua task di mesin / hanya satu aktivitas di mesin itu.
Group Name
Label bebas untuk pelaporan mesin yang dikelompokkan.
Doff Priority / Min Remain Task
Menunda pekerjaan demi Doffing bila sisa kunjungan ≥ Min Remain Task menit. Diatur per setup, dan di Production Simulation bisa juga per mesin.
WLM / Output model
Hasil simulasi yang disimpan di WL_Outputmodels, dengan versi.
Inherited condition
Kondisi awal mesin + seed dari hasil tersimpan untuk memutar ulang simulasi.
